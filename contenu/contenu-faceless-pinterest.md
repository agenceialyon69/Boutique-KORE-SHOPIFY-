# 📌 Contenu sans visage — Pinterest KORE
> Stratégie Pinterest pour KORE activewear : zéro visage, zéro échantillon requis pour démarrer.
> Pinterest = trafic evergreen (une épingle peut ramener des visites pendant 2 ans).
> Dernière mise à jour : 2026-06-09

---

## Pourquoi Pinterest pour KORE

| TikTok | Pinterest |
|---|---|
| Visage souvent nécessaire | ✅ Jamais de visage requis |
| Durée de vie : 24-48h | ✅ Durée de vie : 6 mois à 2 ans |
| Vidéo obligatoire | ✅ Image fixe suffit |
| Algorithme imprévisible | ✅ SEO = résultats prévisibles |
| Sans échantillon = difficile | ✅ Fonctionne avec images CJ propres |

**Verdict red team :** Pinterest ne remplace pas TikTok à long terme, mais c'est le meilleur levier gratuit MAINTENANT — avant l'échantillon, sans visage, avec les images CJ déjà disponibles.

---

## Setup (15 minutes, une seule fois)

1. Créer un compte **Pinterest Business** (gratuit) : pinterest.com/business
2. Nom du compte : **KORE** ou **KORE Activewear**
3. Lier le site : **korewear.fr**
4. Activer le **catalogue Shopify** (Pinterest app dans Shopify → synchronise les produits automatiquement)
5. Créer 3 tableaux :
   - `Leggings Femme — KORE`
   - `Tenues de Sport Femme`
   - `Activewear Seamless`

---

## Types d'épingles à créer (sans visage, sans échantillon)

### Type 1 — Épingle produit (image CJ propre)
- Prend une image produit CJ **sans filigrane**
- Ajoute un bandeau texte en bas : `Legging Sculptant KORE — 34,90 €`
- Lien : fiche produit Shopify
- Outil gratuit : **Canva** (template Pinterest 1000×1500 px)

### Type 2 — Citation / motivation
- Fond coloré (noir, beige, lilas) + texte blanc
- Exemples :
  - *« Le bon legging change tout. »*
  - *« Sculpte. Bouge. Conquiers. »*
  - *« Taille haute. Tête haute. »*
- Logo KORE en bas à droite

### Type 3 — Guide tailles (épingle utile = sauvegardée)
- Tableau des tailles visuel
- Titre : `Comment choisir sa taille de legging seamless ?`
- Très sauvegardé = beaucoup de portée organique

### Type 4 — Flat lay produit
- Legging plié proprement sur fond uni (sol carrelé, marbre, tissu)
- Pas de mannequin, pas de visage
- Outil : téléphone + lumière naturelle

---

## Fréquence recommandée

- **5 épingles / semaine** minimum (Pinterest récompense la régularité)
- Utilise **Tailwind** (outil de planification Pinterest, gratuit jusqu'à 20 épingles/mois)
- Mélange : 3 épingles produit + 1 citation + 1 guide/conseil
