## ÉTAPE 4 — OPTIMISATION DU PANIER

### Bundle principal — « Pack Duo » (2 leggings)
- **Proposition :** 2 leggings `[remise crédible, ex. -10 % ou 2ᵉ à -X € — À DÉFINIR, marge à valider]`.
- **Justification :** un legging qui plaît se rachète en 2ᵉ coloris ; le pack **monte l'AOV** ET
  **atteint le seuil de livraison offerte** (résout l'incohérence 34,90 € < 80 €).
- **Impact AOV :** **fort**.
- **Confiance : Moyen-fort** (sous réserve de marge réelle pour financer la remise `[À CONFIRMER]`).
- ⚠️ Omnibus : remise réelle, jamais de faux prix de référence.

### Upsell post-achat — 2ᵉ legging / autre coloris
- **Proposition :** après paiement, proposer un **2ᵉ coloris** à `[remise — À DÉFINIR]`.
- **Justification :** intention maximale, zéro friction sur la conversion initiale.
- **Impact AOV :** fort.
- **Confiance : Moyen** (dépend des coloris réellement dispo + marge).

### Cross-sell — pièce complémentaire activewear
- **Proposition :** brassière / top assorti `[uniquement si tu comptes le sourcer]`.
- **Justification :** panier « tenue complète », cohérent.
- **Impact AOV :** modéré.
- **Confiance : Faible** aujourd'hui — boutique quasi mono-produit. **À reporter** jusqu'à un 2ᵉ produit réel.

> Reco : démarrer **Pack Duo + upsell 2ᵉ coloris**. Cross-sell plus tard.

## ÉTAPE 6 — STACK SHOPIFY (apps légères, perf préservée)

### Avis — **Judge.me** (reco) / alt Loox
- **+** : plan gratuit solide, léger, avis vérifiés ; **–** : photos = payant ; **Perf** : faible impact.
- **Cas idéal** : démarrage budget serré, avis **réels** uniquement (remplace les faux placeholders — cf. AUDIT #3).

### Bundles — **Shopify Bundles** (natif, reco) / alt Fast Bundle
- **+** : natif, gratuit, impact perf ~nul ; **–** : mise en avant limitée ; **Perf** : excellent.
- **Cas idéal** : le « Pack Duo » 2 leggings.

### Upsell — **post-purchase natif Shopify** / alt ReConvert
- **+** : upsell après paiement, zéro friction conversion, pas d'impact page produit ; **–** : moins personnalisable.
- **Cas idéal** : proposer le 2ᵉ coloris après l'achat.

### Email — **Shopify Email** (natif, reco démarrage) / alt Klaviyo
- **+** : natif, gratuit jusqu'à un volume, automations bienvenue/abandon ; **–** : scénarios avancés limités ; **Perf** : aucun impact front.
- **Cas idéal** : les 5 e-mails ci-dessus. Passer à Klaviyo quand le volume le justifie.

> 🔴 Perf = conversion (70 %+ mobile). **Natif d'abord**, chaque app tierce doit se justifier.
> Quick win lié : **compresser les images** + activer **Shop Pay/Apple/Google Pay** (cf. AUDIT).

## ÉTAPE 7 — ARCHITECTURE TECHNIQUE (thème Horizon) — *PLAN, code en attente de validation*

> ⚠️ **Aucun code généré ici.** Particularité KORE : la boutique est **en ligne** mais le thème
> Horizon **n'est pas dans ce dépôt** (ce dépôt = contenu + `agent/`). Deux voies d'application :
> (A) **manuellement** dans Personnaliser (le plus sûr pour un non-dev), (B) via l'**agent** `agent/`.

### Fichiers / zones concernés (thème Horizon, OS 2.0)
| Élément | Rôle |
|---|---|
| Modèle produit (`product`) | Ordonne les sections de l'Étape 3 sur la fiche legging |
| Sections/blocks Horizon | Hero, problème/solution, squat-proof, bénéfices, caractéristiques, guide tailles, FAQ, garantie, CTA |
| Barre d'annonce + bandeau réassurance | Corriger délai **5-10 j** + seuil livraison offerte |
| Réglages thème (couleurs/typo) | Charte KORE (crème/anthracite/doré) — déjà définie |
| App blocks (Judge.me, Bundles) | Insérer avis réels + Pack Duo |

### Risques techniques
- **Délai faux encore en ligne** (2-5 j) → corriger en priorité (réassurance + fiche + FAQ).
- **Mise à jour thème** peut écraser des édits manuels → noter les changements.
- **Perf mobile** : images non compressées + apps tierces → ralentit (70 % des ventes).
- **Texte en dur** vs traduisible ; **accessibilité** de l'accordéon FAQ.

### Plan d'implémentation (petites étapes validées)
1. **Corriger délai 5-10 j** + seuil livraison offerte (barre + fiche + FAQ) — *priorité absolue*.
2. Coller le **copy optimisé** (étapes 1-2) section par section.
3. Mettre **Guide des tailles** (vraies mesures) + **photos/vidéo squat-test réelles**.
4. Installer **Judge.me** (supprimer faux avis), **Shopify Bundles** (Pack Duo).
5. Activer **paiements express**, **compresser images**, vérifier **mobile + vitesse**.
6. Re-tester en ligne (capture) → confirmer que rien n'a cassé.

➡️ **Validation requise avant code.** Dis « go archi » et indique la voie (A manuel guidé, ou
B via `agent/`) → on attaque point par point, en commençant par le **délai** (le plus risqué légalement).

## ÉTAPE 8 — AUDIT CRITIQUE GLOBAL (honnête)

- **Augmente réellement les ventes :** correction **délai 5-10 j** + **seuil port**, **guide des
  tailles**, **preuve squat-proof réelle**, garantie/retour sous CTA, **Pack Duo**, avis réels.
- **Améliore surtout la confiance :** délai honnête, marque unifiée KORE (fin « ŌKEI »), images
  sans filigrane, zéro allégation minceur, pages légales OK.
- **Améliore surtout l'esthétique :** wording, mise en forme — utile, secondaire.
- **Reportable :** cross-sell (mono-produit), Klaviyo, A/B slogans, ReConvert.
- **Hypothèses à valider :** compo, mesures réelles, coloris, frais/qui-paie retour, marge (pack),
  preuve d'opacité (photos/vidéo). Et le **trafic** (1ʳᵉ vidéo TikTok) reste le vrai levier restant.

## SORTIE — PRIORISATION (étapes 1 → 8)

**PRIORITÉ HAUTE**
- Corriger **délai → 5-10 j** partout (légal + avis).
- Régler **livraison offerte** (seuil vs 34,90 €) — ou pousser Pack Duo.

**PRIORITÉ MOYENNE**
- Pack Duo + upsell 2ᵉ coloris, FAQ/caractéristiques complétées, paiements express, compression images.

**PRIORITÉ BASSE**
- Cross-sell, Klaviyo, A/B slogans/CTA, polish visuel.

- Compo, mesures réelles, coloris, frais/qui-paie retour, marge pack, preuve d'opacité.
- Tests : après correction délai + guide tailles → mesurer **taux de retour** et **conversion** ;
  après 1ères ventes → collecter **vrais avis**.
