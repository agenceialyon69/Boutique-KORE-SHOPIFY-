# Pinterest — pack de lancement KORE (clé en main)

5 tableaux créés ✅. Place aux épingles. **C'est l'épingle (image + lien) qui amène la vente,
pas le tableau.** Chaque épingle = image + titre + description + **lien vers la boutique** + tableau.

---

## ÉTAPE A — Récupère tes 5 liens (une seule fois)
Ouvre chaque page sur ta boutique → copie l'URL dans la barre du navigateur. Note-les ici :

- Collection **Leggings** : `korewear.fr/collections/__________`
- Collection **Brassières** : `korewear.fr/collections/__________`
- Collection **Shorts & Jupes** : `korewear.fr/collections/__________`
- Collection **Ensembles** : `korewear.fr/collections/__________`
- Fiche de l'**ensemble violet** (ton échantillon) : `korewear.fr/products/__________`

> Ces liens sont le « lien de destination » de chaque épingle. **Sans lien, pas de vente.**

---

## ÉTAPE B — Comment publier une épingle (le geste à répéter)
1. **Créer → Épingle**
2. **Importer l'image** (un fichier `KORE-pin-...png` ou une photo produit propre).
3. **Titre** + **Description** (copie depuis la banque ci-dessous).
4. **Lien de destination** = l'URL correspondante (étape A).
5. **Choisir le tableau**.
6. **Publier.**

## ÉTAPE C — Rythme
- **Aujourd'hui :** publie les **3 épingles KORE prêtes** (1, 2, 3).
- **Cette semaine :** ajoute les épingles produit (4, 5, 6) + 2-3 variantes.
- **Ensuite :** **2-3 épingles/semaine**, régulier.

## La vérité (red team)
Pinterest **ne fait pas de ventes du jour au lendemain** — c'est un canal qui **monte sur
quelques semaines** puis travaille longtemps. Ce setup est le bon et il est **gratuit**. La
première vente viendra du **cumul** : épingles + vraies photos + régularité + tes vidéos TikTok.
